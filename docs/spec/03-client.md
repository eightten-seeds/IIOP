8. 告警中心

11. 巡检任务

## 2. 首页驾驶舱

至少展示：
- 设备总数
- 在线/离线/故障/维修数量
- 今日巡检任务
- 完成率
- 活跃告警
- 待处理工单
- 设备风险分布
- 最近 7 天告警趋势
- 最近 7 天巡检趋势
- 工单状态分布

ECharts：
- 折线图
- 饼图
- 柱状图
- 仪表盘可选

数据必须来自真实后端接口，不写死到组件。

## 3. Three.js

三维设备场景必须具备实际业务用途：

- 加载 glTF/glb 设备模型
- 根据 dev_device.model_url 加载模型
- 根据 position_x/y/z 放置设备
- 根据设备状态改变标识效果
- 点击模型选中设备
- 显示设备名称、状态、风险等级
- 可跳转设备详情

没有真实模型时允许先用几何体占位，后期替换。

## 4. Vue Flow

用于“巡检流程设计”。

节点建议：
- 开始
- 检查项
- 条件判断
- 异常上报
- 拍照取证
- AI 分析
- 创建工单
- 结束

第一版只需支持：
- 节点添加
- 连线
- 拖拽
- 删除
- 保存 JSON
- 加载 JSON

不实现复杂 BPMN 引擎。

## 5. 实时通知

PC 顶部通知入口通过 WebSocket 实时接收：
- 告警
- 巡检
- 工单
- AI 诊断完成

断线重连。
历史通知从 REST API 获取。

## 6. AI 页面

AI 诊断页面包括：
- 设备选择
- 异常描述
- 最近巡检摘要
- 最近告警摘要
- AI 风险等级
- 可能原因
- 排查步骤
- 维修建议
- 安全提示
- 工作流节点执行状态
- 人工确认按钮

页面明确显示“AI 结果仅供辅助判断”。

## 7. HarmonyOS

移动端只覆盖现场高价值场景，不复制 PC 后台。

页面：
1. 登录
2. 首页
3. 今日巡检
4. 巡检任务详情
5. 巡检项填写
6. 异常上报
7. 设备详情
8. 告警消息
9. 我的工单
10. 工单处理
11. AI 辅助诊断
12. 通知中心
13. 个人中心

必须复用同一套网关 REST API。

## 8. 移动巡检流程

登录
→ 今日巡检
→ 进入任务
→ 查看设备
→ 逐项填写
→ 必要时拍照
→ 异常项上报
→ 完成任务
→ 后端产生异常
→ AI/维修流程异步处理

第一版设备识别可采用设备码输入/选择。
如果后续 DevEco 环境稳定，再增加扫码。
